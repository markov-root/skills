# Sources

Provenance for the chart-layer knowledge this skill carries (ADR 0002): the
palette validator's metrics and thresholds, the colour space used to construct
the bundled neutral theme, and every external standard asserted by a file under
`knowledge/`. One row per source; linked, never transcribed. Field semantics per
`~/Skills/docs/standard.md` §10.

**A knowledge rule asserting an external standard carries a row here; a rule
stating a specific value without one is a defect.** The only values that may
appear in `knowledge/` without a row are _attributed examples_ — observations of
a named corpus, marked as such, binding nobody (ADR 0008 §2). The convention
that marks one is a blockquote opening `**Attributed example.**`, and
`dev/tools/check-knowledge-provenance.py` enforces the distinction.

## Threshold provenance

- **Contrast thresholds are cited, not chosen.** 4.5:1 (text) and 3:1
  (non-text) come from WCAG 2.2 success criteria 1.4.3 and 1.4.11, verified
  against the W3C Recommendation text on the access date.
- **The adjacent-pair distance minimum is NOT a cited threshold.** No primary
  public source prescribes a minimum colour distance between adjacent
  categorical palette colours. The metric (CIEDE2000) is cited above; the
  numeric minimum is a **declared design choice** made per theme in
  `encoding.check.palette_min_de00` (the bundled neutral theme declares its
  own, with the same statement in situ). When a theme declares no value,
  `theme check` reports measured distances without a pass/fail verdict rather
  than borrowing an unsourced number.
- No content in this file, in `scripts/cli/theme.py`, or in the bundled theme
  is transcribed from the `dataviz` built-in (ADR 0002).
