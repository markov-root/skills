# Engineering knowledge sources

This register contains externally owned factual provenance, not best-practice guidance or project
policy. Each source appears once. `Groups` are stable relationship targets used by knowledge
frontmatter; `Informs` names the authored knowledge files that synthesize the source. Status is one
of `verified`, `unverified`, `paywalled`, or `archived`. Dates record repository review, not a claim
that the source can never change.
