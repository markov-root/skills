# presentation knowledge — index

The standard's rules for building a talk. Read only the file the task routes you to.

**The repository outranks this knowledge.** A consumer repository configures the standard in
`presentations.toml`, puts its brand in a token file, and records its own decisions as ADRs. Where
those say something different, they win. What is written here is the default, and the vocabulary
the `present` CLI enforces.

**What a command enforces is marked.** A rule tagged `[enforced: <command>]` is checked by that
command. Everything else is guidance an agent applies and a reviewer checks.
