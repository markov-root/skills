# Genre routing and bounds

Voice legitimately differs by genre because genres are _social actions_ with
different reader needs, proof standards, pacing, and trust signals. So never ask
"make this sound good" — **route by the rhetorical situation**: audience, purpose,
medium, genre, stakes, and the reader task. Formality is a gradient (distance,
shared background, institutional risk, medium), not a binary.

Classify first, then route. These are **bounds and obligations**, not templates
to fill — a genre tells you what the piece must earn and where the point must
arrive, then you write in the resolved voice.

## Routing table

| Purpose                         | Genre                 | Voice                         | Structure it must satisfy                                     | Revise hardest for                        |
| ------------------------------- | --------------------- | ----------------------------- | ------------------------------------------------------------- | ----------------------------------------- |
| Help the reader _do_ a thing    | technical / how-to    | direct helper                 | goal · prerequisites · steps · verification · troubleshooting | task success                              |
| Define exact behavior           | reference / API       | precise, neutral              | object · parameters · examples · errors                       | completeness, no ambiguity                |
| Change belief/action (commerce) | copy                  | reader-centered persuasive    | problem · outcome · proof · call-to-action (AIDA / PAS)       | specificity, proof, ethics                |
| Argue or explore an idea        | essay / long-form     | intelligent conversation      | question · thesis-in-motion · examples · implications         | surprise, coherence, less abstraction     |
| Report research                 | academic / scientific | disciplined evidence          | IMRaD or field template                                       | claim–evidence fit, limitations, citation |
| Get a decision or action        | memo / email          | concise professional          | BLUF · context · options · recommendation · ask + deadline    | decision clarity                          |
| Inform the public quickly       | journalism            | neutral, factual              | lede · attribution · descending importance                    | verification, balance, no buried lede     |
| Immerse / entertain             | narrative / fiction   | character- and world-specific | scene vs. summary · conflict · change                         | stakes, pacing, sensory detail            |
| Feed / thread (short)           | social                | native, human                 | one promise per unit, hook first                              | nuance moved to replies/links             |

## Per-genre obligations (what "failed" means)

- **Technical / API.** Calm, second-person, task-oriented; accuracy,
  scannability, active voice, stable terminology. Route through **Diátaxis**:
  tutorial (encouraging) · how-to (brisk procedural) · reference (terse exact) ·
  explanation (conceptual). A beautiful page missing error cases has failed.
- **Essay / long-form.** Curious, plainspoken, idea-led; write like you talk,
  then filter through clarity and revision. Authority is earned by insight; the
  thesis is often discovered while drafting.
- **Marketing / copy.** Lead with the reader's problem, the outcome, the proof,
  the next action. Specificity beats adjectives; use the customer's language;
  stay truthful (AIDA when staged, PAS when the pain is already salient).
- **Academic / scientific.** Explicit claims, evidence, method, limitations,
  citation; cautious but not evasive.
- **Business / memo / email.** The recommendation, decision, request, or risk
  arrives early (**BLUF**); an Amazon-style narrative fits complex strategy where
  reasoning matters more than slide compression.
- **Journalism.** Accuracy, attribution, impartiality, plain language, inverted
  pyramid; the lede carries the most newsworthy fact — never bury it.
- **Fiction / narrative.** Dramatize important moments in _scene_, compress the
  rest in _summary_; embodied, sensory, character-filtered, rhythmically
  intentional. "Show, don't tell" is a useful default, not a law — strong
  narrative uses both.
- **Social / threads.** Hook in the first line, one idea per unit, platform-native
  formatting, human specificity; move nuance to replies, never inflate into
  clickbait.

## Structure heuristics (choose, don't default)

- **Top-down** (thesis/recommendation first — Minto pyramid, BLUF, inverted
  pyramid) fits business, policy, docs, news, argument.
- **Bottom-up** (generate, then find the structure) fits discovery essays,
  fiction, exploratory research.
- **BLUF / inverted pyramid** suits memos, exec summaries, incident reports, and
  many web pages, but is weak for suspense, discovery, literary essays, and
  narrative persuasion.
