# Sources

Provenance for the `writing` skill's knowledge base — the style tradition and
pre-writing questions, the AI-writing-tell catalogue, and voice/register routing.
A row records that the source was reviewed on the accessed date, not that every
synthesized claim is permanently true. Product- and corpus-behavior claims are
**volatile** — re-verify frequencies, tool behavior, and the em-dash/sycophancy
status before changing what a knowledge file asserts.
